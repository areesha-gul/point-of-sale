================================================================================
GRAIN TRADING POS - SETUP INSTRUCTIONS
================================================================================

STEP 1: INSTALL NODE.JS (if not installed)
-------------------------------------------
Download and install Node.js 18 or higher from: https://nodejs.org
Verify installation: node --version

STEP 2: INSTALL BACKEND DEPENDENCIES
-------------------------------------
1. Open Command Prompt or PowerShell
2. Navigate to backend folder:
   cd "d:\projects\point of sale\backend"
3. Install dependencies:
   npm install
4. Wait for installation to complete (2-3 minutes)

STEP 3: INSTALL FRONTEND DEPENDENCIES
--------------------------------------
1. Navigate to frontend folder:
   cd "d:\projects\point of sale\frontend"
2. Install dependencies:
   npm install
3. Wait for installation to complete (2-3 minutes)

STEP 4: INITIALIZE DATABASE
----------------------------
1. Make sure you're in backend folder:
   cd "d:\projects\point of sale\backend"
2. Run initialization:
   npm run init-db
3. You should see:
   "Database tables created successfully"
   "Default admin user created (username: admin, password: admin123)"

STEP 5: START THE APPLICATION
------------------------------
Option A - Start both servers together:
1. Navigate to root folder:
   cd "d:\projects\point of sale"
2. Start both:
   npm run dev

Option B - Start separately (recommended for beginners):
1. Open TWO Command Prompt windows

   Window 1 (Backend):
   cd "d:\projects\point of sale\backend"
   npm run dev
   (Should show: "Server running on port 5000")

   Window 2 (Frontend):
   cd "d:\projects\point of sale\frontend"
   npm run dev
   (Should show: "Local: http://localhost:5173")

STEP 6: OPEN AND LOGIN
-----------------------
1. Open your web browser
2. Go to: http://localhost:5173
3. Login with:
   Username: admin
   Password: admin123

================================================================================
COMMON ISSUES & SOLUTIONS
================================================================================

Issue: "Port 5000 is already in use"
Solution: Stop the other application or change port in backend/.env

Issue: "Cannot find module 'better-sqlite3'"
Solution: Make sure you ran 'npm install' in backend folder

Issue: "Database locked"
Solution: Close all node processes: taskkill /F /IM node.exe (Windows)

Issue: Frontend shows "Network Error"
Solution: Make sure backend is running on port 5000

Issue: "npm not found"
Solution: Install Node.js from nodejs.org
